# 章节文件模板

所有章节文件统一使用本结构。元信息头是给校验脚本与状态重建用的，正文区是读者看到的。

```markdown
<!--
章号: 0001
标题: 章节标题
卷/批次: 第 1 卷 / 第 1 批次
情绪标签: 爽+燃
伏笔操作: plant:F-001, payoff:F-000
字数: 2013
-->

# 第0001章 章节标题

{承接上章钩子的句子——用一句动作或对话接住上章悬念，禁止复述上章内容}

{核心事件展开：进入本场冲突，主角在做事、做选择。目标 1800-2200 字，含 1-2 个张力波峰}

{小高潮：按细纲的情绪标签兑现——爽（打脸/升级/收获，必须有见证者）、燃（热血/守护，短句加速）、
泪（具体细节，禁止直接抒情）、压（危机加深，为下章爆发蓄力）}

{收束 + 钩子：本章矛盾阶段性了结，最后 1-3 句抛出未解决张力（悬念/危机/期待），收尾即断，禁止总结陈词}
```

## 写作纪律（对应 Phase 3 步骤 2）

| 位置 | 要求 |
|------|------|
| 首段 | 300 字内进入冲突；禁止天气/梦境/身世自述开场；静态描写不超过 100 字 |
| 全章 | 对话占比 ≥ 30%；至少 1 个可被记住的元素（金句/名场面/反转/人物高光） |
| 张力 | 连续 500 字无冲突必须引入新张力 |
| 章末 | 必须有钩子；钩子类型不得与前两章连续重复 |
| 全文 | 不出现设定词典之外的设定名词；不出现主线状态卡之外的能力 |

## 待避免的 AI 腔（润色步骤对照）

四字堆砌、"心中涌起复杂的情感"、"一种说不出的感觉"、每段都有的顺畅过渡词（随后/紧接着/与此同时）、
人物对话像念设定、重复出现的外貌与心理描写。
