# 人物弧光与世界观自洽

## 主角设计

**魅力四件套**：魅力点（让人喜欢/佩服的具体特质）、明确目标（可验证）、致命缺陷（会犯错、有代价）、变化弧光（随卷实质成长）。

- 主角可以不完美，但每卷必须有一处**实质变化**：实力升级、认知刷新（对世界/自己的理解变了）、关系重构。写了几十章主角毫无变化 = 弧光死亡。
- 主角的"变强"要伴随"变贵"：能力越强，责任/风险/代价越大，这是长篇不崩的第二根支柱。
- 主角不装、不圣母、不无敌：决策符合其性格与信息边界（只能基于他知道的信息做判断）。

## 配角设计（拒绝工具人）

配角**记忆点三件套**：
1. **一个标签**：口头禅、习惯动作、外形特征、反差萌（越简单越记得住）
2. **独立动机**：他为什么跟着主角？他自己的目标是什么？
3. **关系演化**：与主角的关系必须随剧情变化（结拜→嫌隙→和解 / 忠诚→动摇→背叛）

配角下场原则：重要配角不写死则已，写死必须换回巨大的情绪价值或剧情价值；退场配角留"钩子式余地"（读者知道他没死透/会回来）。

## 反派设计（反派有逻辑，冲突才好看）

- **反派三问**：他想要什么？他为什么觉得自己有道理？他的能力凭什么构成威胁？
- 反派是主角目标的"镜像"或"代价"：主角走 A 路线，反派走了同起点的 B 路线，对比产生深度。
- 反派强度阶梯：本书每个大阶段至少一个"打不过、只能绕/忍/借力"的强敌，压迫感是爽感的原料。
- 反派败亡必须有铺垫、有回合、有代价，禁止"突然降智送人头"。

## 力量体系自洽（长篇崩坏第一大源头）

立项时在 00-总纲 中定死 v1 规则，之后所有章节严格执行：

1. **等级阶梯**：名称 + 每级能力边界（能做什么/不能做什么）。边界比名称重要。
2. **升级条件与代价**：资源/机缘/风险，三者至少占其一。无代价升级 = 张力死亡。
3. **禁区清单**（违反即重写）：无铺垫越级碾压；等级贬值（前期大boss后期杂兵）；能力凭空出现（词典外新造）；前文致命伤后文消失。
4. **社会结构挂钩**：力量体系决定社会形态（谁掌握力量，谁掌握话语权与资源），设定才立得住。
5. **新设定准入**：新设定名词出现前，先检查是否与已有词典冲突；首现必须给上下文线索（读者不需要翻回第 3 章也能懂）。
6. **设定词典维护**：04-设定词典.md 记录名词/首现章/读者已知范围/完整真相（若对读者有信息差），每章回写。

## 情感线设计（爽感之外的共鸣）

- 每卷至少一条情感线有推进：亲情/友情/爱情/师徒/家国，任选，但必须真实（有来处、有代价）。
- 情感场面靠**具体细节**打动人（一碗放凉的面、一句没说出口的话），不靠直接抒情。
- 泪点投放遵循稀缺原则，见 emotion-and-pacing.md。
