# 黄金三章与开局设计

网文读者给一本书的时间只有三章（约 6000 字）。三章必须完成"钩住—亮牌—兑现"的完整回路。

> **为什么是这三章**：平台的追读率（次章留存）主要看**前 3 章与前 10 章**，
> 判定窗口在 6000 字以内就关闭了。前面写得再好，收益给在第 15 章——读者在平台的
> 判定窗口里根本没拿到回报。**开局的账，只能开局还。**
>
> 这一节的所有阈值都由 `scripts/quality_check.py` 判定，跑一次就会在开头打印
> 「留存速览」，不用靠感觉。

## 第一章：命运改变之日

**任务：让读者产生"我想知道接下来会怎样"。**

- **前 300 字内**必须出现以下三选一：异象（反常事件）/ 冲突（正面碰撞）/ 困境（主角陷入麻烦）。第一句话就要有信息量或张力，禁止天气描写、梦境开场、身世自述开场。
- **以"遭遇"呈现设定**：世界观信息通过主角正在经历的事件带出，禁止静态介绍（"在这个大陆，人们分为九个等级……"是死路）。
- **主角必须在做事**：应对麻烦、做出选择、展现性格。读者先爱上"这个人的反应"，才愿意了解设定。
- **章末钩子 = 命运改变点**：金手指出现前兆 / 巨变降临 / 真相一角。本章结束时，主角的生活轨迹必须被打破。

## 第二章：金手指亮相

**任务：亮出本书的核心卖点。**

- 金手指正式登场并**小试牛刀**：第一次使用，解决一个小麻烦或带来第一次小甜头——这是第一个小爽点。
- 主角**亲口说出目标**（或内心明确确立）：为读者立起"追读的路标"。目标要具体（报仇/活下去/变强到某级/找到某人），不要宏大空洞。
- 补齐必要关系：给主角一个"关系锚点"（亲人/朋友/恩人），让主角有软肋，读者有牵挂。
- 章末钩子：金手指的代价或秘密初现 / 新威胁逼近。

## 第三章：第一次净收益

**任务：让读者合上这一章时，手里是**多**了东西的，而不是又少了一样。**

- 收益必须是**净的**：「付出了什么、换回了什么」算完账要为正。用十二次换一条出路、
  代价是丢掉半生记忆——这是净亏损，不是收益（《刻名》第 7 章的真事）。
- 兑现的**形式不限于打脸**。打脸只是爽文赛道最常见的一种，见下节「净收益的六种形态」。
- **有旁观者更好**：爽感的一半来自「主角的变化被看见」。但不是硬要求——
  悬疑流的见证者可以是一份档案、一枚旧印、一句别人的转述。
- 章末抛出更大的目标或威胁，让第三章的收益自然引出第四章的追读动力。

## 净收益的六种形态

收益 = **主角（或读者）的处境，在结算后变好了**。六种形态，任何一条都算数：

| 形态 | 说明 | 例 |
|------|------|-----|
| **胜利** | 正面赢下一场对抗 | 打赢、过关、活下来且带着战利品 |
| **情报** | 拿到**可以拿去用**的线索 | 「这锁上刻的字跟他手心的一样」→ 能顺着去查 |
| **道具** | 得到一件具体的东西 | 通行牌、一份旧档、一件遗物 |
| **盟友** | 关系推进、有人站到他这边 | 有人肯替他作证、肯一起走 |
| **位置** | 身份/名分/处境上升 | 登记在册、拿到资格、脱掉「无籍」 |
| **结算** | 情绪上的释放与安放 | 委屈被说破、误会解开、悼念完成 |

### ⚠️ 情报收益必须是「可用的」

「读者知道了更多，但主角更糊涂了」**不算收益**——那是把谜团又拧紧了一圈。
可用与否的判据很简单：**他能不能拿这条信息去做一件事？**
不能，就只是新的悬念，不是收益。

### ⚠️「微爽」不算收益

自评时最容易骗自己的一句话是「这一章其实有点爽」。判定口径：
**这一章结束时，主角手里的东西比开始时多了吗？** 没有，就是成本章。

> 这条规矩是从《刻名》的实战里长出来的：第 7 章标的是「压(微爽:活下来)」，
> 可那一章他丢了半生记忆、只换到「能出门」，评审原话是「**这是净亏损**」。
> 后来全书前 14 章零收益、追读率持续走低，起点就是这种自我安慰。
> 脚本现在会点名这种带批注的标签（`check_tag_hygiene`）。

## 开局窗口硬指标（由脚本判定）

平台的追读率判定窗口基本在**前 3 章与前 10 章**内关闭。这三条是硬门槛：

| 指标 | 阈值 | 脚本 |
|------|------|------|
| 前 3 章兑现次数 | ≥ 1 | `quality_check.py` → `check_opening_retention` |
| 前 10 章兑现次数 | ≥ 2 | 同上 |
| 前 10 章收益次数（兑现 + 情报） | ≥ 3（约每 2-3 章一次） | 同上 |
| 连续「只有成本、没有收益」的章数 | ≤ 2 | `check_emotion_rhythm` |
| 两次兑现之间的空档 | ≤ 8 章（**从第 1 章起算**） | 同上 |
| 软钩（短句留白 / 对白悬停）占比 | ≤ 60% | `check_hook_variety` |

跑一次 `quality_check.py` 会先在开头打「留存速览」，把这几个数直接摊在眼前——
**告警可以被忽略，速览不行。**

## 开局死法清单（自查）

| 死法 | 说明 |
|------|------|
| 开局睡觉/穿越眩晕三章 | 前 2000 字无冲突 |
| 退婚流只说不做 | 退婚后一直在"发誓"而非行动 |
| 三章全是设定介绍 | 力量体系、宗门、历史背景倾泻 |
| 主角无目标 | 读者不知道追什么 |
| 金手指万能无代价 | 张力死亡，后劲全无 |
| 全程无人旁观 | 爽点无见证者，情绪无法传递 |
| **连续 3 章只有成本** | 每一章都在"失去"，读者跟着连亏——第三次开始疲，第五次开始弃 |
| **章末全靠软钩** | 每章都收在氛围或对白上，读者读完没得到新东西，也就没有点下一章的理由 |
| **标签写「微爽」自我安慰** | 用批注代替结算；账面好看，追读照掉 |

## 不同赛道的开局变体

- **升级流**：第一章末必须见到"升级路径的第一级台阶"
- **悬疑流**：第一章末抛出核心谜团，第三章给出第一个（不完整的）答案
  ——⚠️ 追加硬约束：**第三章那个"不完整的答案"必须是可用的**。
  给完答案之后，主角要能凭它去做一件事（去某个地方、换某样东西、拒绝某个人）。
  只把谜团拧得更紧不算兑现，这正是《刻名》开局吃亏的地方：
  前三章给足了"这是怎么回事"，从没给过"我能拿它干什么"。
- **言情流**：前两章完成男女主的高张力初遇，第三章完成第一次心动或误会
- **无限流**：第一章内进入第一个副本，规则以"生存威胁"呈现

## 一句话自检

> 读完第三章，读者能不能说出「他拿到了什么」？
>
> 说不出 → 不管文笔多好、谜团多勾人，这本书在平台的追读窗口里已经掉队了。
