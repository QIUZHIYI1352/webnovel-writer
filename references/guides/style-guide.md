# 文笔辨识度、去 AI 味与反套路

## 去 AI 味（每章润色必查）

| 病灶 | 症状 | 处方 |
|------|------|------|
| 四字堆砌 | "心潮澎湃、热血沸腾、璀璨瑰丽"连用 | 一段最多一个四字格；其余用具体动作替代 |
| 抽象情绪 | "心中涌起复杂的情感" | 改为具体动作/对话/生理反应（"他捏紧了拳，指节发白"） |
| 均匀句长 | 全是 20-30 字的长句 | 长短句交替；情绪爆点用短句、独句成段 |
| 对话报幕 | 人物说话像在念设定/表决心 | 对话必须有潜台词、有性格；信息通过"说一半、留一半"带出 |
| 完美过渡 | 每段衔接都顺滑空洞 | 允许跳跃，用场景切换代替"接着/然后/与此同时" |
| 重复描写 | 相同的心理/外貌/场景描写反复出现 | 全书首次出现可细写，之后一笔带过或换新角度 |

润色顺序：先删（病灶）→ 再换（抽象→具体）→ 后调（节奏与句长）。

## 文笔辨识度

- **建立专属语言标记**：给本书定 3-5 个反复出现的"专属梗"（主角的口头禅、独有的比喻方式、固定小仪式），读者靠它们认出这本书。
- **名场面意识**：每卷至少刻意打造 1 个可传播的名场面（一句话能复述的画面），卷细纲中预留位置。
- **画面感公式**：一个具体名词 + 一个动词 + 一个感官细节 > 三个形容词。
- **对话即人**：闭卷测试——只看对话能否分辨出是谁说的。不能 → 补语言标记。

## 反套路：熟悉 + 一次反转

读者要的不是全新，是"熟悉的东西写出新意"：

1. **识别套路**：退婚流、废柴逆袭、系统开局、龙傲天……这些是读者的"舒适区"，不必回避。
2. **一次反转**：保留套路的骨架，在一个关键点上反转——退婚者另有苦衷 / 系统的任务会伤害主角在乎的人 / 天才主角发现升级的代价是记忆。
3. **反转要付代价**：套路反转不是为抖机灵，反转后的设定要真的参与后续剧情（登记进设定词典与伏笔账本）。
4. **反的还是套路不是逻辑**：可以反俗套，不能反常识——世界规则、人物动机必须始终自洽。

## 价值观底线

- 核心价值不歪：努力有回报、恶有代价、守护有意义——不要求深刻，但要求立得住。
- 反派可恶但世界有规则：反派靠手段碾压，不靠"全世界都是蠢人"推进剧情。
- 复杂人性允许存在：配角可以摇摆、反派可以悲情、主角可以犯错——但犯错要有后果，这是"人物弧光"的原料。

## 水字检测（2000 字专用）

逐段自问：**删掉这段，情节受损吗？**
- 无损 → 删（典型水字：重复心理活动、无信息量寒暄、纯风景描写）
- 受损 → 保留并检查能否压缩到 2/3 篇幅
